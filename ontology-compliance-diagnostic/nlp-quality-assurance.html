NLP Quality Assurance

Load an ontology file and check local annotation text for spelling and lightweight grammar issues. The RDF parser, tokenizer, QA state, and persistence all run client-side; no ontology text is uploaded.

Conformance Diagnostic Ontology Measures

Local State Model

Ontology RDF is parsed into memory, annotation rows are checked from memory, and IndexedDB stores the latest editable QA state plus explicit QA run records. File System Access can mirror a saved QA run report into a selected project folder.

Important User Data Notice

This page processes ontology files locally in your browser. The latest QA state and saved QA runs are stored in IndexedDB on this device, folder mirrors use browser File System Access when you choose a project folder, and downloads are generated locally.
